# QR-code-generator

## Tech Stack
* React
* TypeScript
* Next.js
* Tailwind
* Prisma

# Description
- QR Code Generator is a simple web application that allows users to generate QR codes from text or URLs instantly.
The project focuses on clean UI, real-time input handling, and efficient state management using React and TypeScript.
[QR-code-generator](https://deployed-qr-code-generator.vercel.app/)

## Run locally
`npm install`
`npm run dev`
